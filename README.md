# Actividad 5 Spring
## Mi primera aplicación web con Spring

---

### Tecnologías usadas
- **Java 25**
- **Spring Boot 3.5.7**
- **Thymeleaf**
- **Maven**
- **IntelliJ IDEA**

---

### Funcionamiento
1. Ejecuta la clase principal:
   ```
   HelloWorldApplication.java
   ```

2. Abre en tu navegador diferentes url para probarla. Puedes pasar un nombre para que te salude con un mensaje personalizado o no pasar náda y mostrará un mensaje genérico:
   ```
   http://localhost:8080/helloworld
   http://localhost:8080/helloworld?username=Javi
   http://localhost:8080/greeting
   http://localhost:8080/greeting?name1=Ximo&name2=Javi
   ```
